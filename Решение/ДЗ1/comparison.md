# Сравнение AI инструментов для модуля заказов FoodTech

Выбран локальный Codex: он уже доступен в рабочей среде, редактирует Python-файлы
и запускает тесты. Cursor также подходит технически, но требует отдельного
окружения. Bolt и Lovable удобны для веб-прототипа, однако выбранная задача —
локальный Python-модуль с воспроизводимыми тестами.

## Метод оценки

Используется разрешённая заданием **описательная оценка** по шести критериям.
Сравнивается пригодность инструментов для одной задачи, а не рейтинг моделей.
Для Codex выполнена практическая проверка. Остальные инструменты оценены
по официальной документации; аккаунты в них не создавались, одинаковый
бенчмарк на четырёх агентах не выполнялся. Скорость генерации и качество
трёх альтернатив поэтому обозначены как прогноз процесса и непроверенное
качество, а не как результаты измерений.

Обязательные условия выбора: работа с существующей локальной папкой,
выполнение Python 3.12 и unittest, отсутствие новой платной подписки для
этого задания. При соответствии этим условиям предпочтение получает
инструмент с меньшими затратами на настройку.

## Обоснование решения и альтернативы

**Codex** выбран по трём факторам: доступ к локальным исходникам уже настроен,
Python-код можно проверять сразу, проектные инструкции и результаты сохраняются
вместе с кодом. Выбор подтверждён реальным запуском, а не только возможностями
из документации.

**Cursor** — полноценная альтернатива для той же архитектуры. Он не отвергнут
по качеству: сравнительного запуска нет. Его преимущество — постоянная работа
в IDE; в текущем задании оно не компенсирует отдельную настройку.

**Bolt** не подходит для выполнения Python backend в штатной среде. Его стоит
рассмотреть на этапе JS-интерфейса. **Lovable** стоит рассмотреть для отдельного
веб-прототипа с его стеком; для существующего локального Python-проекта
потребуются дополнительные действия. Эти выводы относятся к выбранной задаче.
