# Чек лист выбора LLM и контура обработки

Этот чек-лист дополняет обязательное сравнение агентов из ДЗ1.
Агент управляет инструментами, LLM формирует ответы, а on-premise описывает
место эксплуатации. Выбор IDE сам по себе не делает модель локальной.

## Проверка перед выбором

- [x] Определена задача: локальная Python-логика расчёта заказа.
- [x] Зафиксированы ввод, формула и граничные сценарии.
- [x] Исключены персональные данные и секреты из учебных примеров.
- [x] Проверена работа выбранного агента с файлами и терминалом.
- [x] Учтены новый бюджет и стоимость существующей квоты отдельно.
- [x] Итоговый код проверен тестами, а не только визуальным чтением.
- [ ] Для production проверить договор, хранение запросов, обучение на данных,
  список обработчиков, регион обработки и возможность удаления данных.
- [ ] Для production с персональными данными определить применимые российские
  нормы, включая 152-ФЗ, требования к локализации и трансграничной передаче,
  с ответственным за защиту данных. Российский поставщик сам по себе не
  подтверждает соблюдение всех требований. Этот учебный пакет не даёт
  заключения о правовом соответствии production-системы.
- [ ] Для локальных весов проверить лицензию именно выбранного checkpoint,
  память, скорость на целевой машине, поддержку инструментов и качество русского языка.

## Российские решения и открытые веса

| Вариант | Назначение и контур | Что проверить для проекта |
|---|---|---|
| GigaCode | AI-ассистент разработки; поставщик описывает SaaS и on-premise лицензии [G]. | Поддержку нужной IDE, доступ агента к тестам, состав on-premise поставки и условия договора. |
| YandexGPT в Yandex AI Studio | Модель генерации через сервис AI Studio [Y]. | Нужен отдельный агент или интеграция для работы с файлами; модель API не равна готовой IDE. |
| DeepSeek-R1 | Открытые веса, есть исходная модель и distilled-варианты; лицензии и инструкции опубликованы разработчиком [D]. | Размер выбранного варианта, базовую лицензию distilled-модели, требования памяти и результат на тех же тестах. |
| Qwen3-8B | Конкретный checkpoint с открытыми весами и лицензией Apache-2.0 в карточке [Q]. | Совместимый inference runtime, квантование, размер контекста и качество на проектных задачах. |

On-premise означает установку в инфраструктуре организации; это требует
эксплуатации и проверки исходящих соединений. Открытые веса не гарантируют,
что любой способ их использования исключает передачу данных наружу.
В этой работе локальный inference DeepSeek/Qwen не запускался и его
производительность не заявляется: обязательная практика ДЗ1 выполнена на Codex.

Для сравнения моделей в будущем: дать одинаковую спецификацию и тесты;
сохранить checkpoint, настройки и исходные ответы; измерить время до
проверенного решения, число исправлений, долю пройденных проверок и стоимость.
Проводить несколько запусков, а не ранжировать модели по одному ответу.
