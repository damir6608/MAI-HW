## Быстрая проверка

Требуется Python 3.12 или новее; внешние пакеты и интернет не нужны.
Из распакованной папки `Решение`:

```powershell
python verify.py
```

Ожидаемый вывод:

```text
demo: exit_code=0
tests: exit_code=0
before: exit_code=1
after: exit_code=0
```

`before` намеренно оставлен как исходный ответ без проектных правил: его
семь неуспешных проверок — предмет сравнения, а не ошибка итогового пакета.
Основной модуль проходит 41 проверку, after — 15/15 общих проверок.
Скрипт сам завершается с кодом 0 только при ожидаемых кодах всех четырёх запусков.
Полные результаты записываются в `evidence/`.

Отдельный запуск демо:

```powershell
cd foodtech_demo
python demo.py
python -m unittest discover -s tests -v
```

## Границы проверки

Сравнение альтернатив основано на официальных источниках; практически проверен
Codex. Локальное выполнение кода не означает, что LLM работает без облака.
Эксперимент до/после проведён последовательно в одной сессии; его ограничения
указаны в testing.md. Полный UI, backend-сервер, платежи и production-деплой
не требуются условиями ДЗ1/ДЗ2 и не входят в этот учебный модуль.
