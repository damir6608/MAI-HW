# Учебный модуль заказов FoodTech

Модуль считает стоимость готовых наборов на 1 или 7 дней и проверяет первую
доставку минимум через два календарных дня. Деньги представлены копейками.
Это локальный пример доменной логики для ДЗ1/ДЗ2, без сети и внешних библиотек.

## Запуск

Python 3.12 или новее; из этой папки:

```powershell
python demo.py
python -m unittest discover -s tests -v
```

Ожидается итог 2045000 копеек и 41 пройденный тест.
Для проверки также двух исходных ответов агента выполни `python verify.py`
из родительской папки `Решение`.

## Контракт

- `OrderItem`: цена **за один день** и количество одинаковых наборов.
- `quote_order`: days=1/7, непустой список позиций, дата first_delivery и today.
- Доставка взимается один раз за заказ; скидки не применяются.
- `calculate_total`: сумма списка цен в копейках плюс доставка;
  пустой список допустим, отрицательные значения, bool и float запрещены.
- TypeError означает неверный тип, ValueError — недопустимое значение.
- date принимается без времени; datetime отвергается.
