# Одинаковая задача для двух вариантов

```text
Role: Python-разработчик.
Task: Напиши функцию calculate_total(prices_kopecks, delivery_kopecks=0),
которая считает общую стоимость готовых наборов питания с доставкой.
Context: prices_kopecks — список цен наборов в копейках; доставка также
задана в копейках. Функция возвращает итог в копейках. Python 3.12.
Format: Только исходный код функции в Python-файле.
```

Первый вариант создан в текущей сессии до создания и чтения проектного файла
правил. Для второго варианта используется этот же текст плюс явно подключённый
`../rules.md`. Общие инструкции среды и история текущего чата сохраняются;
это последовательный учебный пример, а не независимый слепой эксперимент.
