# FoodTech — ДЗ3 и ДЗ4

Адаптивный frontend выбора готового питания: каталог с фильтрами, меню и
аллергены, корзина на 1/7 дней, первая доставка и подтверждение демозаказа.
React + Vite + Pico CSS. Данные учебные; реальная оплата, доставка и аккаунты
не подключены. Корзина и подтверждение живут в памяти вкладки и сбрасываются
при перезагрузке. Персональные данные не запрашиваются.

Репозиторий: https://github.com/damir6608/foodtech-hw3-hw4

Онлайн-версия: https://foodtech-hw3-hw4.berrylyric11.chatgpt.site
(приватный доступ владельца через ChatGPT). Для проверки преподавателем
доступны исходники GitHub и локальный запуск без зависимости от Sites.

## Запуск

Проверено с Node.js 24.19 и npm 8.19.3. Нужен современный Node.js (24).
В терминале из корня репозитория:

```sh
cd frontend
npm ci --legacy-peer-deps
npm run dev
```

Откройте URL, который Vite напечатает в терминале, обычно
http://127.0.0.1:5173/. Сервер остаётся запущенным, пока открыт терминал.
Если порт занят, Vite выбирает следующий; ориентируйтесь на его вывод.
Для повторения точного lock-файла используйте npm ci, а не npm update.
В окружении выполнения Codex запуск сборщика потребовал доступа вне
песочницы из-за EPERM при realpath; обычный локальный Node не требует
специальных настроек проекта.

```sh
npm test
npm run build
npm run check:build
npm run preview
```

Production preview по умолчанию: http://127.0.0.1:4173/.
`check:build` запускается после build и проверяет лимит JS+CSS 350 КБ gzip.
Тесты: Vitest + Testing Library, 44 проверки, в том числе 16 компонентных.
Результаты последней проверки находятся в ДЗ4/test-results.json.

## Как проверить основной сценарий

1. Откройте каталог, выберите фильтр и изучите «Смотреть меню».
2. Добавьте «Баланс на каждый день» (900 ₽), выберите 7 дней.
3. В корзине будет 6300 ₽ + 150 ₽ доставки = 6450 ₽.
4. Нажмите «К оформлению», выберите дату не раньше сегодня + 2 дня и интервал.
5. Подтвердите демонстрационный режим и отправьте форму.
6. На экране появятся номер, дата, период и итог; корзина очистится.

Кнопки +/− меняют количество от 1 до 9; ноль удаляет позицию. Доставка
150 ₽ добавляется один раз на заказ. Цена в карточке всегда за один день.
Ссылка «Личный кабинет» показывает границы гостевой демоверсии.

## Проверка ошибок

Добавляйте параметр к корневому URL до hash, например
`http://127.0.0.1:5173/?demo=submit-error`.

| Параметр | Результат |
|---|---|
| `?demo=catalog-error` | Ошибка каталога и повтор запроса; пока параметр активен, сбой повторяется |
| `?demo=empty` | Пустой каталог и недоступное оформление |
| `?demo=submit-error` | После заполнения формы ошибка оформления; корзина и форма сохраняются |
| `?demo=unauthorized` | Mock-ответ 401 при отправке; гостевое сообщение без успешного заказа |

Для возврата к обычному режиму удалите query-параметр и перезагрузите страницу.
Пустая и ранняя дата проверяются без параметров. Загрузку и успешное
восстановление после временной ошибки проверяют автоматические тесты API-адаптера.

## Ограничения демонстрации

Каталог — локальный JSON, отправка — Mock API с задержкой 450 мс.
Тестовый номер не является идентификатором реальной покупки. Недельный заказ
означает количество готовых наборов на семь дней и единую стоимость доставки
в учебной модели; расписание реальной логистики не моделируется.
Аллергены и БЖУ приведены как демонстрационные данные, меню фиксировано.
Скриншоты подтверждают проверенные размеры и состояния; полноценный аудит
всех браузеров и тестирование с пользователями не проводились.
